# EEPROMTool v0.4 – Android App

Ein einfaches Android-Tool zum Bearbeiten von ECU/EEPROM-Dateien direkt auf dem Gerät.  
Unterstützt `.bin`, `.eep`, `.e2p` – kein Root nötig.

## 🔧 Funktionen
- VIN anzeigen und ändern
- IMMO off
- DTC off
- Checksummen (CKS) korrigieren
- Explorer-basierte Dateiauswahl
- Echtzeit-Loganzeige und Fortschrittsbalken

## 🖼️ GUI
- Klar strukturierte Oberfläche
- VIN-Feld, Checkboxen für Funktionen
- „Jetzt speichern“-Button generiert neue Datei (`*_mod.bin`)
- Protokolliert alle Schritte in einer Logbox + optionaler `.log`-Datei

## 📱 Voraussetzungen
- Android 8.0 oder höher
- Kein Root erforderlich

## 📦 Installation
Lade die neueste APK unter „Releases“ herunter und installiere sie manuell.
